# Contributing
If you would like to contribute code to this project you can do so through GitHub by forking the repository
and sending a pull request.
Before RDK accepts your code into the project you must sign the RDK Contributor License Agreement (CLA).

Pull requests targeting `develop` must use a categorized Conventional Commit title:

`<type>(<scope>): <subject>`

Allowed scopes are `api`, `webkit`, and `tooling`. Use `tooling` for documentation and certification-app changes. Examples: `feat(api): Add device capabilities` and `fix(tooling): Correct certification result parsing`.
