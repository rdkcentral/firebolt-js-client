# References

This page provides links to external resources and specifications related to the Firebolt Web API.

## Specifications

### Firebolt 9 Core API Specification

The official Firebolt 9 Core API specification, maintained by RDK Central:

- [Firebolt 9 Core API Specification](https://wiki.rdkcentral.com/spaces/WG/pages/468770558/Firebolt+9+Core+API+Specification)

This specification defines the complete Firebolt 9 API surface, including:
- Module definitions
- Method signatures
- Type definitions
- Platform-specific APIs (Web vs Native)
- Versioning and deprecation policies
