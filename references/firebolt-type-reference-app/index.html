Firebolt Type Reference App

This is a reference application for testing Firebolt TypeScript definitions.

Open this project in VS Code to test IDE features:

  • Intellisense for module names (Accessibility, Device, etc.)
  • Hover documentation for methods and parameters
  • Autocomplete for method parameters
  • Type checking for incorrect usage
  • "Go to Definition" navigation

Check the browser console for any runtime output.
